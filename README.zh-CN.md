# CheckinPilot

[English](README.md) | **简体中文**

CheckinPilot 是一个 Chrome 浏览器扩展，可以帮你自动领取 AI API 面板站点的每日签到奖励。只需要设置一次，之后照常打开 Chrome，它就会每天替你签到——不需要粘贴密码，也不需要运行任何脚本。

> 当前状态：早期版本（`v0.1.0-rc`）。目前唯一完整验证过的站点是 [`https://runanytime.hxi.me`](https://runanytime.hxi.me)。

## 特色

- **一次设置，之后不用管** —— 默认在你每天第一次打开 Chrome 时自动签到，也可以改为你指定的每日时间段。
- **绝不索要任何密码** —— 直接复用浏览器里已有的登录状态，从不需要你提供密码、Cookie、令牌或 API Key。
- **只碰你明确添加的站点** —— 你不添加，它就不会访问；每个站点都要通过 Chrome 自带的权限提示单独授权。
- **数据只保存在本机** —— 没有后台服务器、没有统计上报、没有遥测；历史记录经脱敏处理，在本地保留 30 天。

## 环境要求

- Google Chrome **114 或更高版本**（桌面版）。
- 一个受支持站点的账号（见[支持的站点](#支持的站点)）。

## 安装（约 3 分钟，无需编程）

CheckinPilot 尚未上架 Chrome 应用商店，需要通过 ZIP 压缩包安装：

1. 打开 [GitHub Releases](https://github.com/Auroraee/checkin-pilot/releases) 页面，下载最新的 `checkin-pilot-*-chrome.zip`。
2. 右键压缩包 →「全部解压缩」，选择一个你会长期保留的文件夹（例如 `文档\CheckinPilot`）。扩展使用期间不要删除这个文件夹。
3. 把 `chrome://extensions` 复制粘贴到 Chrome 地址栏并打开。
4. 打开右上角的**开发者模式**开关。
5. 点击**「加载已解压的扩展程序」**，选择刚才解压出来的文件夹（即包含 `manifest.json` 的那一层）。
6. （建议）点击 Chrome 工具栏的拼图图标，把 CheckinPilot 固定到工具栏，方便随时点开。

日后更新：下载新的 ZIP，解压覆盖同一个文件夹，然后在 `chrome://extensions` 里点击 CheckinPilot 卡片上的**重新加载**图标。

卸载：在 `chrome://extensions` 的 CheckinPilot 卡片上点击**「移除」**，再删除那个文件夹即可。

## 添加第一个站点

1. 在 Chrome 里像平时一样**登录**你要自动签到的站点。
2. 停留在该站点的页面上，点击工具栏的 **CheckinPilot 图标**。
3. 点击**「添加当前站点」**。Chrome 会弹出权限提示，询问是否允许 CheckinPilot 访问这一个站点——选择**「允许」**。（权限提示出现时弹窗可能会自动关闭，这是正常现象，扩展会自行完成添加。）
4. 在确认面板中核对信息，然后点击**「确认」**。

完成——这个站点从现在起每天自动签到。其他站点重复同样的步骤即可。

## 每天会发生什么

- 默认使用**启动模式**：每天第一次打开 Chrome 时，CheckinPilot 自动执行当天的签到。
- 想固定时间？在设置里切换为**时间窗模式**：设定开始和结束时间（默认 08:00–10:00），签到会在该时间段内随机挑一个时刻执行（期间 Chrome 需处于运行状态）。
- 如果时间窗内 Chrome 一直关闭，CheckinPilot 会在你**当天**下次打开 Chrome 时补跑；如果当天 Chrome 完全没有打开，这一天就跳过——错过的签到不会跨天补签。
- 各站点依次签到；今天已经手动签到过的站点会自动跳过。
- 默认只在需要你处理时（例如登录过期）或签到最终失败时才发 Chrome 通知；「签到成功也通知」是可选项，默认关闭。

## 修改设置

点击 CheckinPilot 弹窗里的齿轮图标（或在扩展图标上右键 →「选项」）：

| 设置项 | 作用 |
| --- | --- |
| 每日签到时间 | 启动模式，或每日时间窗。时间跟随本机时钟。 |
| 签到成功时通知 | 签到成功时也发送通知（默认关闭）。 |
| 管理站点 | 暂停/恢复某个站点，或永久移除它。 |
| 历史记录 | 过往签到的脱敏结果，最新在前（保留 30 天）。 |

「暂停」只是停止该站点的自动签到，配置仍然保留，你随时可以点「立即签到」手动执行；「移除」不可恢复，同时收回该站点的访问权限。

## 支持的站点

| 站点 / 平台 | 状态 |
| --- | --- |
| [`https://runanytime.hxi.me`](https://runanytime.hxi.me) | ✅ 已验证 —— 支持全自动签到（含其工作量证明步骤）。 |
| 使用经典会话登录的 New API 面板 | ⚠️ 自动识别 —— 通常可用，具体以运行时对站点的探测结果为准。 |
| 仅令牌登录的 New API、官方 Sub2API | ❌ 暂不支持。 |

对于签到协议不受支持的站点，CheckinPilot 会提供**访问模式**：每天在后台标签页中短暂打开一次该站点，以防有些站点仅凭页面加载就会发放奖励。此类结果在历史记录中标记为「未验证」。

界面语言跟随 Chrome 的界面语言（支持英文和简体中文）。

## 常见问题

**它会保存我的密码或令牌吗？**
不会。CheckinPilot 复用浏览器中已有的登录状态——不需要你粘贴任何机密信息，也不会把站点的凭据复制出去。详见 [PRIVACY.md](PRIVACY.md)。

**站点登录过期了怎么办？**
你会收到通知，提示先去站点重新登录。根据站点情况，之后可能还需要打开该站点，并在弹窗里点击**「更新当前网站」**来恢复自动签到。

**它会绕过验证码（CAPTCHA / Turnstile）吗？**
绝不。出现人机验证时，CheckinPilot 会停下来并通知你到站点上手动完成签到。

**解压出来的文件夹必须保留吗？**
是的——Chrome 从该文件夹加载扩展，删除它扩展就会失效。

**我在站点上换了账号怎么办？**
自动签到会暂停，直到你确认新的绑定：用新账号打开该站点，点击**「更新当前网站」**并确认。

## 隐私与安全

- 无后台服务器、无统计、无遥测；所有数据都保存在本机的浏览器配置中。
- 没有 `<all_urls>` 全站访问权限——每个站点都需单独通过 Chrome 的权限提示授权，且仅限 HTTPS。
- 每个站点只绑定一个账号；检测到换号会暂停自动化，等你重新确认。
- 绝不绕过 CAPTCHA 和交互式 Turnstile 验证。
- 受支持的工作量证明在可随时取消的 worker 中运行，并设有严格的单站点每日限额。
- 历史记录经过脱敏，只在本地保留 30 天，每个站点最多 100 条。

完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发者指南

环境要求：Node.js 22 或更高版本、pnpm 11 或更高版本、Chrome 114 或更高版本。

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build     # 未打包扩展输出到 .output/chrome-mv3
pnpm zip       # 发布压缩包输出到 .output
```
