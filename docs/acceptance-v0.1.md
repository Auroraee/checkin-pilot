# v0.1 验收门槛

## `v0.1.0-rc` 测试包

- 从干净检出使用锁文件安装依赖后，可以复现构建 Chrome Manifest V3 ZIP。
- 类型检查、单元测试及模拟站点端到端测试全部通过。
- 自动化场景至少覆盖：站点登记与逐 origin 授权、本地调度日的全局随机批次与补跑、串行队列、结果去重、有限重试、账号变更、交互式挑战、跨触发方式共享且在同日移除重加后仍不可重置的 PoW 日预算、暂停/重绑/移除、午夜墓碑清理、记录清理和中英文回退。
- 扩展消息、存储、日志及构建产物中不含原始 `localStorage.user` JSON、密码、Cookie 值、Bearer Token 或 API Key；页面窄函数只能返回数字用户 ID。
- 可以在 Chrome 114 或更高版本中完成解压安装、授权、站点绑定、状态查询和手动触发流程。

## GitHub `v0.1.0`

- 在一个尚未签到的自然日，由扩展后台计划或当日补跑在 `runanytime.hxi.me` 完成至少一次真实自动签到；单站手动触发不能替代该项验收。
- 扩展记录与站点状态均确认成功，且没有重复提交。
- 在完成该验证前只能发布带预发布标记的 `v0.1.0-rc`，不能标记为稳定版。

## Chrome Web Store 候选版

- `v0.1.0` 在本地连续稳定运行满 7 个 Chrome 实际开启日。
- 期间没有重复签到、认证秘密落盘、无界重试或后台长时间占用 CPU。
- 全天未打开 Chrome 的日期既不算失败，也不计入 7 个开启日。
