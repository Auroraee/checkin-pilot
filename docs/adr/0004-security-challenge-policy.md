# 只自动处理已知且有界的计算型挑战

扩展可以自动完成已内置、可识别、有硬超时且可取消的签到 PoW，但只接受难度 10–20：每个 challenge 使用单个 Worker 最多计算 12 秒。每个 origin 在一个浏览器本地调度日内，计划签到、当日补跑、网络重试和扩展内手动签到共用最多两次 challenge、Worker 累计最多 24 秒的硬预算；重绑、暂停恢复、重复点击以及同日移除后重新登记都不重置预算，首版也不能调高上限。移除站点后只保留 origin、调度日和已用次数/秒数的本地安全预算墓碑，到本地午夜自动删除。任务完成、超时或取消后立即终止 Worker 并关闭 offscreen 页面；预算耗尽、更高难度、Turnstile、CAPTCHA 和未知挑战绝不绕过，也不在后台任务中突然打开网页，而是记录为“需要用户介入”，发送通知，并仅在用户点击通知后打开对应签到页。
