# 采用 Apache License 2.0

项目采用 Apache License 2.0，并以符合 OSI 定义的开源项目对外发布。该许可证允许商业与非商业场景下的使用、修改和分发，同时提供明确的专利许可与专利诉讼终止条款。

仓库使用标准 `LICENSE` 文件保存完整许可证文本，并使用 `NOTICE` 保留项目归属信息。项目介绍、包元数据、发布资料和贡献指南统一标注为 Apache-2.0。

Issue 与 Pull Request 对外开放。除贡献者另有明确声明外，贡献者有意提交并纳入项目的贡献依 Apache License 2.0 第 5 节按同一许可证授权，不附加额外条款；贡献者保留其版权。当前不要求签署 CLA。

本决定取代 ADR 0007 与 ADR 0009 中基于 PolyForm Noncommercial 1.0.0 的许可及贡献策略。
