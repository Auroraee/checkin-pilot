# 源码公开但禁止商业使用

此决定曾采用 PolyForm Noncommercial 1.0.0：允许个人及该许可证列明的非商业组织使用、修改和分发，但商业使用必须另行取得授权。由于非商业限制不符合 OSI 开源定义，当时的 README、发布页和商店资料统一使用“源码公开”或“source-available”。

该决定已由 [ADR 0011](0011-apache-2.0-license.md) 取代；项目现按 Apache License 2.0 开源。
